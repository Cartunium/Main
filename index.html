SOS led blink

September 2026

Projektbeskrivelse

Projektet går ud på at lave et SOS signal med en LED, samt lærer while, for og if loops.

Kildekode / Resultat

// from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)

while True:
    for i in range (3):
        sleep(0.25)
        led.value(1)
        sleep(0.25)
        led.value(0)
    
    sleep(0.5)

    for i in range (3):
        led.value(1)
        sleep(0.5)
        led.value(0)
        sleep(0.5)

    for i in range (3):
        led.value(1)
        sleep(0.25)
        led.value(0)
        sleep(0.25)
    
    sleep(2)

Refleksion & Læring

  • Reletive simple steps gjorde det nemt at lære hvordan loops fungerer. Wokwi er også et nemt værktøj til at eksperimentere med elektronik og programmering.
  • Til at starte med opretede jeg bare variabler og plusede dem med 1 for hvert loop ind til der var gået 3 gange for jeg gik videre til næste bogstav i SOS, men for i in range gør den proces meget nemmere.

Forløb 3

Ret 5 fejl

September 2026

Projektbeskrivelse

Vi skal rette 5 fejl i en eksisterende kode og forstå, hvordan man fejlfinder og retter koder.

Kildekode / Resultat

// import time
from machine import Pin #1 omvendt rækkefølge

LED = Pin(5, Pin.OUT)
pausetid = 0.50
time.sleep(0.1) #2 punktum ikke komma
x=0
print("Hello XXXXXX")

while True:
    x = x+1
    for i in range(9): #3 glemt ":"
        if (0 <= i < 3) or (5< i < 9):
            pausetid = 0.5
            if (i == 2) or (i ==8):
                print("s", end="")
                time.sleep(0.5)
        else:
            pausetid = 1
            if (i==5):
                print("o", end="") #4 skal rykkes en op før at if loopet virker
                time.sleep(0.5)
        LED.value(1)
        time.sleep(pausetid) #5 lille p da variablen i starten er med lille
        LED.value(0)
        time.sleep(pausetid)
    print(" ", x)
    time.sleep(2)

Refleksion & Læring

  • Man lærer at ligge mærke til og følge de små regler man skal følge når man skriver kode, samt hvordan man fejlfinder og retter koder.
  • Jeg sad lidt fast på den sidste, men spurgte Kristoffer som hurtigt forklarede den femte.

Forløb 4

Ultrasonisk sensor

September 2026

Projektbeskrivelse

Vi skal implementere en ultrasonisk sensor i vores projekt og bruge den til at måle afstande.

Kildekode / Resultat

// import machine
from machine import Pin
import time

trig_pin = Pin(7, Pin.OUT)
echo_pin = Pin(6, Pin.IN)
led = Pin(5, Pin.OUT)

while True:
    trig_pin.value(0)
    time.sleep_us(2)
    trig_pin.value(1)
    time.sleep_us(10)
    trig_pin.value(0)
    duration = machine.time_pulse_us(echo_pin, 1, 30000)
    tid = round(340.00*duration/2000000, 2)
    print(tid, "m")
    if tid <= 1.5:
        led.value(1)
    else:
        led.value(0)
    time.sleep(0.25)

Refleksion & Læring

  • Det var interessant at bruge ultrasoniske sensorer og forstå hvordan man måler afstande med hjælp af lyd og derved indrage fysik.
  • Kendte ikke til time_pulse_us funktionen så det tog lidt tid at forstå hvordan den virkede.

Knap LED

September 2026

Projektbeskrivelse

Vi skal få en knap til at kontrollere en LED baseret på knaptryk.

Kildekode / Resultat

// import time
import machine
from machine import Pin

knap = Pin(11, Pin.IN)
led = Pin(5, Pin.OUT)

while True:
    knapValue = knap.value()
    if knapValue == 1:
        led.value(1)
        time.sleep(0.1)
    
    else:
        led.value(0)
        time.sleep(0.1)

Refleksion & Læring

  • Ligesom i tidligere projekter er det interessant at lærer nye måder at håndtere kode, men også at se de samme koncepter og regler anvendt igen.
  • Man skulle lige undersøge hvordan knappen skulle sættes op, men selve koden var ikke særlig kompleks.
